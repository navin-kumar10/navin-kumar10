```
🏗️  INFRASTRUCTURE AS CODE     Everything is versioned, reviewed, and reproducible.
                                Terraform modules, CloudFormation stacks — no manual clicks in prod.

🔄  PIPELINE FIRST              Before writing app code, I think pipeline.
                                Build → Test → Scan → Stage → Deploy → Monitor.

🔭  OBSERVABILITY BY DEFAULT    Metrics, logs, and traces from day one.
                                Not an afterthought. Not optional. Always on.

🔐  SECURITY SHIFT LEFT         Trivy scans in CI. Secrets in AWS Secrets Manager.
                                IAM least-privilege. TLS everywhere. Basic SOC practices.

🚀  ZERO DOWNTIME PHILOSOPHY    Rolling deployments, blue-green strategies, DB upgrades
                                with controlled execution — reliability is non-negotiable.

☁️  CLOUD NATIVE THINKING       Managed services over self-hosted where it makes sense.
                                Elastic scaling, high availability, and cost-awareness always.

👥  TEAM-FIRST CULTURE          DevOps isn't a role — it's a shared culture.
                                I mentor, document, and build systems teams can own.
```
